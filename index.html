Backup, organize, deduplicate, and monitor your systems with one lightweight CLI. Pure Python stdlib — no dependencies, no bloat.

Batteries included, zero deps

Everything runs on Python standard library. Install once, run forever.

💾 Smart Backups

Compressed ZIP or tar.gz archives with timestamped names, automatic pruning of old backups, and cross-platform paths.

📁 File Organizer

Sort downloads and folders by extension instantly. Move or copy mode. Handles thousands of files in seconds.

🔍 Duplicate Finder

MD5-based deduplication across any directory tree. Lists groups of identical files for review or cleanup.

💚 Health Checks

Disk usage, memory stats, uptime, and full system reports in JSON. Perfect for monitoring scripts and cron jobs.

One command, zero config

Drop-in CLI that works immediately.

# Backup your projects python -m src.cli backup ~/projects /mnt/backups --prune --keep 7 # Organize Downloads by file type python -m src.cli organize ~/Downloads --move # Find duplicate files python -m src.cli duplicates ~/Downloads # Full system health report python -m src.cli health # Disk usage summary python -m src.cli usage /home/user
